Set up a workspace in three commands



1. Create the workspace
meta init writes the manifest and a .gitignore.


2. Add each repo
Give it a short name and its git address.


3. Check the list
meta repo list draws the workspace as a tree.


The terminal on the left types itself and loops. Output is trimmed from a real meta 0.83.0 run on a demo workspace; the git addresses are examples. Commands: meta init, then meta repo add NAME URL for each repo, then meta repo list. Add --with-skill to init to install the Claude Code skill at the same time.
