One command answers the question: where does everything stand? Output is from a real run on the six-repo demo workspace, with blank lines trimmed. For a product manager this is the honest status of a feature that spans repos. Pull, push, fetch, checkout and sync fan out the same way: meta git pull, meta git checkout -b feature/x.
