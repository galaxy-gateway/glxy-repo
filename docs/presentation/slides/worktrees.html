Daily workflow

One branch, every repo, no stashing.

$ meta project add my-app git@github.com:acme/my-app.git
$ meta worktree add feature/x --all

Projects are bare by default. Each branch is its own folder, and a worktree_init hook can run your install step on creation.

workspace/
└── my-app/
    ├── .git/       bare repo
    ├── main/       default branch
    └── feature-x/  new worktree

Bare-first layout is the default; set default_bare to false in .meta (or bare false per project) for traditional clones. Cross-repo worktrees are what make parallel work, human or agent, cheap.
