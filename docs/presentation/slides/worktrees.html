The same branch name gets its own folder in every repo. Your main folders stay untouched, so there is nothing to stash.


A worktree is a second checkout of the same repo in its own folder. With --all, meta creates the branch and its folder in every repo, so a cross-repo feature has one name everywhere. Output is trimmed from a real run; infra, sdk and worker get a folder too. Projects are bare by default, and a worktree_init hook can run an install step when a worktree is created. meta worktree list, remove and clean manage them afterwards.
