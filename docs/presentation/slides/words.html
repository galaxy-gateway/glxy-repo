Plain language

Five words to know

These five cover the whole talk. Each one shows the command where you will meet it.

Repo

One project's code together with its full history.

meta repo add

Workspace

A folder that holds many repos side by side.

meta init

Manifest

The file that lists which repos belong.

.metarepo

Fan out

Run one command in every repo at the same time.

meta exec --all

Worktree

A second folder for the same repo, on another branch.

meta worktree add

A glossary slide so nobody is left behind, product managers especially. Read each word once and point at the command underneath it; the next five slides teach those commands one at a time.
