meta -w git status

all 6, from anywhere

Scope is directory-aware. Inside a project, meta acts on that project. Inside a folder of projects, it acts on the ones beneath it. At the root, it acts on everything. The -w flag (--workspace) forces the whole workspace from anywhere, and --project or --projects pick repos by name. The folder layout here is an example.
