What it is

One manifest lists your repos.

{
  "projects": {
    "api": "git@github.com:acme/api.git",
    "web": "git@github.com:acme/web.git",
    "tooling": "git@github.com:acme/tools.git"
  },
  "scripts": { "test": "cargo test" }
}

A .meta file at the workspace root. The repos stay independent: own history, own remotes, own CI.

meta CLI

plugins: git, exec, run, worktree

api

web

tooling

The manifest is plain JSON (YAML and TOML also work via meta init --format). Projects map a name to a git URL or local. Scripts live in the same file. The CLI is a thin core plus plugins; the plugins do the work across the child repos.
