AI on the CLI

Four ways to make an agent fluent in meta

Context packs

A skill or CLAUDE.md that says what meta is and when to use it. Install with meta init --with-skill.

Callable tools

An MCP server so any MCP-capable harness can run meta git and meta exec directly.

Workflows

Slash commands, subagents and hooks. For example, a worktree per open PR with tests in each.

Configuration

Permission allowlists, MCP registration and workspace discovery tie the rest together.

From docs/HARNESS_INTEGRATION.md. Note the distinction: a meta plugin extends the CLI; a harness integration teaches an external agent to use the CLI. A good setup uses all four types together.
