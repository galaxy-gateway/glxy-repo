Who gets what

What each role gets

Developers

  • One command instead of a loop over folders.
  • A branch across repos without stashing.
  • Scripts and agent skills shared from one place.

Product managers

  • One status view for a feature that spans repos.
  • One branch name per feature, so it is easy to ask about.
  • Several agent tasks in progress without collisions.

Repos keep their own history, remotes and CI. Nothing is migrated.

Two audiences, one tool. Developers save the manual loop. Product managers get a single place to ask where a feature stands, because the feature has the same branch name in every repo it touches. Adoption is low risk: meta adds a manifest beside the repos and changes nothing inside them.
