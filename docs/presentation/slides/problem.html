A change that touches several repos means the same steps by hand in each one. People lose track, and an AI agent has no map of the fleet.

The same six repos, now scattered. Each has drifted in its own way: different lint versions, stale branches, unsaved work. These labels are illustrative examples, not data. The cost is the manual loop for any cross-repo change, and agents suffer most because nothing tells them which repos exist.
