The problem

Ten repos. Ten copies of everything.

api

eslint 8, CI template v1

web

eslint 9, CI template v3

worker

its own scripts folder

infra

no agent instructions

docs

three branches behind

sdk

uncommitted changes

A cross-repo change means N clones, N branches and N pull requests, all by hand. An agent working across them gets lost.

Make this relatable: everyone has a folder of repos that drifted. Each card is a repo with its own flavour of drift. The cost is the manual loop for cross-repo work, and agents suffer most because they have no map of the fleet.
