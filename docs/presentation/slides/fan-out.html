meta exec runs any shell command in each repo; --parallel runs them side by side. The results table is real output from the demo workspace. Statuses are ok, failed, skipped or cloned, and a skipped repo always says why (uncommitted changes, no upstream). meta run NAME does the same for scripts saved in the manifest; meta run --list shows them.
