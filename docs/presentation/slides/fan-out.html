Daily workflow

Fan out

Any command, every repo, in parallel.

Named scripts

meta run build
meta run --list

Scripts live in .meta, so the team shares them.

Directory-aware

cd plugins/
meta git status

Scope follows your cwd. Use -w for everything.

Scope rule: inside a project it acts on that project; inside a folder of projects it acts on those; at the root it acts on all. The -w flag forces the whole workspace from anywhere.
