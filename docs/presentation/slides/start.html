Get started

Five commands to a working fleet.

$ cargo install --path meta
$ meta init --with-skill
$ meta project add api git@github.com:acme/api.git
$ meta git status
$ meta worktree add feature/x --all

Source and docs: github.com/caavere/metarepo. Start with README.md and docs/PRODUCT.md.
