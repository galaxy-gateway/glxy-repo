Nested workspaces

A team workspace lives inside an org workspace. By default meta acts on the nearest one; add --root to drive the outermost, and -w to span all its projects.

meta git status
meta --root -w git status

org workspace

team-a

svc-1

svc-2

team-b

svc-3

svc-4

Each team can work at its own level without seeing the whole org, while platform or release work can reach everything from the outer root.
