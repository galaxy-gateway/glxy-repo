AI on the CLI

Give every agent its own worktree

One worktree per task means parallel agent sessions never trip over each other, and one meta command reaches all the repos a task touches.

api

feature/auth

chore/deps

This is the key slide for the AI-on-the-CLI audience. Each agent session gets an isolated checkout, so there is no stash juggling and no cross-contamination. The same worktree add command with --all creates the branch in every repo. On screen, the same api repo appears once per agent, each in its own folder.
